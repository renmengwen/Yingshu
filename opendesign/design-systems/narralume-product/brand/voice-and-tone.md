# 文案语气

## 品牌声音

Narralume 像一位克制的制作统筹：说清当前对象、动作和结果，不扮演创作伙伴，不夸大智能，不用“魔法”“一键成片”“让灵感绽放”等泛 AI 话术。

## 基本规则

- 默认中文，句式短而具体。按钮使用动宾结构：`导入 TXT`、`生成分镜`、`开始渲染`。
- 标题使用句式大小写；英文产品名写作 `Narralume`，不全大写充当装饰。
- 不使用 emoji。没有现成图标时，用文字标签，不用 Unicode 符号冒充图标。
- 页面标题不加句号；说明句使用全角中文标点；数字和单位之间按中文习惯不留空格，如 `24章`、`03:42`。
- 文件名、编码、路径、任务 ID 保留原始大小写并使用等宽字体。
- 不把系统拟人化。用“已识别 24章”，不用“我为你找到了 24章”。

## 状态模板

| 状态 | 结构 | 示例 |
| --- | --- | --- |
| 空状态 | 当前事实 + 下一动作 | `书库为空。导入 TXT 后开始整理章节。` |
| Loading | 正在 + 具体动作 + 可选范围 | `正在索引《潮汐档案》，请稍候…` |
| 成功 | 已 + 结果 + 关键数量 | `导入完成，共识别 24章。` |
| 失败 | 对象 + 失败原因 + 可执行下一步 | `原文读取失败：文件已移动。请重新定位源文件。` |
| 中断 | 动作 + 已中断 + 数据处置 | `导入已中断，未完成的临时文件已清理。` |
| 危险确认 | 不可逆后果 + 对象名称 | `删除后无法恢复“潮汐档案”的本地索引。` |

错误信息优先展示可处理原因；技术错误码放在“详细信息”内，不让堆栈进入主提示。状态变化写入 `aria-live="polite"`；阻断性错误才用 `role="alert"`。

## 语气变化

- 创建与浏览：平静、简短，减少说明性文案。
- 长任务：给出阶段、对象和中断能力，不虚构百分比。
- 数据风险：直接、完整，不用委婉词。
- 首次引导：解释工作流价值，不使用营销口号。
