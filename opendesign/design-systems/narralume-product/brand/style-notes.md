# 视觉与组件规范

## 设计方向

暖中性工业编辑风借鉴纸张、剪辑台和出版校样的质感，但不做复古拟物。科技感来自清晰层级、等宽元数据、精确状态和紧凑工作区。主要画面是连续工作台，不是卡片陈列页。

## 色彩

- `surface-canvas`：全局画布；浅色为暖纸灰，暗色为暖石墨。
- `surface-primary`：栏、面板和阅读区；大多数容器使用它。
- `surface-secondary` / `surface-inset`：选中行、输入槽、代码或时间线轨道。
- `accent-primary`：唯一品牌强调色，用于主按钮、选中标记、链接和焦点辅助；禁止铺满大面积背景。
- 状态色只表达语义。成功绿、警告赭黄、失败红必须同时带图标或文字。
- 禁止渐变作为主背景，禁止半透明玻璃表面和外发光。

## 排版

- UI：`IBM Plex Sans` 优先；中文回退到思源黑体、苹方或微软雅黑。正文 14px，关键操作不小于 14px。
- 原文：可使用思源宋体一类中文衬线，14–16px、1.9倍行高；不要把衬线体用于表格和按钮。
- 元数据：等宽字体，11–12px；适用于编码、时间、序号、路径和任务 ID。
- 页面标题 28px/600，面板标题 16px/600，标签 11px/600 并可使用 0.08em 字距。中文标题不强制大写式装饰。
- 单行长文本省略，必须提供原生 `title` 或可访问的完整值；原文正文允许自然换行。

## 空间与布局

- 基础单位 4px；常用间距 8、12、16、20、24、32、40px。
- 桌面工作台优先 16–20px 面板间距与 12–16px 内边距；不要用 32px 以上内边距制造空洞感。
- 书库页保留三栏：书籍 280–340px、章节 300–380px、原文填满余量。窄屏降为单栏步骤流，不压缩成不可读三列。
- 工具栏高 48–56px；普通控件高 40px，触控命中区至少 44px。

## 圆角、边框与阴影

- 行、按钮和输入框 4–6px；面板 6–10px；不用胶囊形按钮，除非是短状态标签。
- 面板主要靠 1px `border-subtle` 分层；选中态使用 `border-strong`、`accent-soft` 或 2px 内嵌标记，不能只靠颜色。
- 常驻面板不投影。下拉、对话框、浮动菜单可使用 `shadow-raised`。

## 动效与交互

- hover/focus 120ms，面板展开或浮层 180ms；使用 `cubic-bezier(0.2, 0, 0, 1)`。
- hover 只改变一层表面或边框；按下态轻微降低亮度，不做缩放弹跳。
- 异步提交立即禁用触发器，按钮文案改为进行时；若允许中断，提供同层级次按钮。
- 不用持续呼吸光、背景粒子和无含义扫描线。进度未知时用克制的线性不定进度，不伪造百分比。
- `prefers-reduced-motion: reduce` 时移除非必要过渡。

## 组件

- 主按钮：铜色实底，高对比文字；每个局部区域通常只有一个主按钮。
- 次按钮：透明底 + 强边框；危险按钮默认保持克制，确认层才使用红色实底。
- 列表行：整行可点，显示标题和最多一行元数据；选中态同时使用背景、边框或位置标识。
- 面板：标题栏、可选工具栏、内容区；避免把每条数据再包一层圆角卡片。
- 状态条：占据工作区上方的稳定位置，避免加载时布局跳动；包含状态标签和具体消息。
- 输入：标签常驻，placeholder 只给格式示例；错误在控件下方用文本解释。
- 对话框：只用于需要阻断或确认的操作；普通详情使用侧栏或面板。
- 数据表：数字右对齐，名称左对齐，状态用文本标签；表头保持低对比，不用全大写英文。

## 图标与图像

- 优先使用项目已安装的 `shadcn/ui` 配套图标方案；当前无图标依赖时使用文本按钮，不新增长依赖只为少量图标。
- 图标为 16 或 20px、1.5–2px 描边，必须有可访问名称或与可见文本组合。
- 禁止 emoji、Unicode 符号假图标和手绘复杂 SVG。
- 素材缩略图展示真实画面，不叠加装饰性霓虹滤镜。缺图用带明确类型文字的中性占位块。

## 可访问性

- 正文与背景对比度至少 4.5:1，大字至少 3:1；状态色与相邻色至少 3:1。
- 所有交互支持键盘；使用 `:focus-visible` 和 `shadow-focus`，不得移除焦点轮廓而无替代。
- 触控目标至少 44×44px。仅图标按钮必须有 `aria-label` 与 tooltip。
- 主题切换使用按钮组或菜单，暴露当前状态；默认跟随系统，用户可恢复“跟随系统”。
- 避免仅以颜色表示选中、错误、完成；同步提供文本、形状或位置变化。
- 空状态、loading 和错误状态不应让屏幕阅读器重复播报；使用合适的 live region。
