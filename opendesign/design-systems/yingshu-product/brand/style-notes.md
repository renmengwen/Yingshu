# 视觉与交互规范

## 视觉方向

“冷中性媒体控制台”服务于视频项目、媒体资产、生产状态与审核任务。冷白和石墨是工作表面，信号蓝只表达可执行主操作和当前选择。界面不借用纸张、书页、墨水、铜棕、中文衬线正文或阅读型大段铺陈。

## 色彩

- `surface-canvas` 是应用画布，`surface-primary` 是主工作面，`surface-secondary` 用于工具栏和低权重分区。
- `surface-selected` 只用于当前行或当前候选，同时必须保留文本或形状信号。
- `accent-primary` 是唯一品牌操作色；不得大面积铺底，不与紫色组成渐变。
- 成功、警告、失败和信息色只表达状态，并始终配中文状态文本。
- 明暗主题保持相同语义层级，不简单反相。

## 排版

- UI 和长文案均使用现代中文无衬线；不设“阅读字体”特例。
- 页面标题 30px/620，阶段标题 20px/620，分区标题 16px/620，正文 14px/1.55。
- 长旁白在详情层使用 14–16px、1.75 行高，不使用衬线体。
- 段落号、画面号、修订号、时长、任务 ID、Hash 与规格使用等宽字体。
- 表格单元格只放 1–2 行摘要；完整文本必须有“查看”入口。

## 布局和密度

- 桌面最大内容宽度 1440px；阶段顶部包含标题、状态、关键统计和操作。
- 主体优先“工具栏 + 表格 + 分页”，避免把每条记录做成圆角卡片。
- 4px 基础间距；常用 8、12、16、20、24、32、40、48px。
- 同一区域不连续嵌套页面框、区块框、标签框和输入框；分组依靠留白、表面和表头。
- 桌面无需滚到列表末尾即可完成阶段主操作。

## 圆角、边框和阴影

- 输入、按钮和表格工具 4–8px 圆角；Dialog 和 Sheet 12px；不用胶囊主按钮。
- 常驻区域不投影；Dialog、Sheet、Popover 使用 `shadow-raised` 或 `shadow-popover`。
- 默认控件一层 `border-subtle`；Hover 改为 `border-strong`；Focus-visible 仅保留一个 2px 焦点轮廓。
- 错误态用错误边框和文字；焦点仍只保留一个外轮廓，不允许父标签重复描边。

## 组件

- Button：高度至少 44px；主按钮信号蓝实底，次按钮透明或次级表面，危险实底只出现在确认层。
- Input/Textarea/Select：常驻标签、清楚的帮助和错误文本；placeholder 只给格式示例。
- Table：语义化表头、明确状态列和操作列；状态不只靠颜色；每页默认 10 条，可切换 10/20。
- Pagination：显示总数、上一页、页码、下一页；数据变化后回到有效页，关闭详情后保持原页。
- Dialog/Sheet：标题、记录上下文、关闭入口、主次操作；初始焦点、焦点循环、Esc、焦点返回、未保存拦截齐全。
- Status：短标签说明结果，邻近文本说明原因和下一步。
- Toolbar：放筛选、批量操作、页大小和当前选择数量。
- Sticky Action Bar：显示未保存计数、修订兼容性、批准门禁和当前主操作；为底部内容预留空间。

## 图片和图标

- 候选缩略图使用真实生成图；设计样板没有真实素材时使用带中文类型标签的中性占位图。
- 不手绘复杂 SVG，不用 emoji 或 Unicode 字符冒充图标。
- 保存、生成、上传、下载、重试、删除、返回、关闭、设置等动作按钮使用 `lucide-react` 中语义匹配的图标配合中文动宾标签；图标位于文字前，常规尺寸为 16px，并作为装饰对辅助技术隐藏。
- 图标不得替代文字；分段选择、是非确认和高密度行内操作在图标不能提升识别度时保持纯文字，禁止为了统一形式添加无意义图标。
- 只有关闭、展开、翻页等通用且无歧义的控件允许纯图标，并必须同时提供可访问名称和 tooltip。

## 响应式

- 1440px 和常见桌面宽度使用完整表格。
- 390px 下表格转为紧凑记录列表，只保留编号、摘要、状态和主操作；页面本身无横向溢出。
- Dialog 在窄屏下接近全屏，操作区固定可见；所有触控目标至少 44×44px。
- 粘性操作栏不得遮挡最后一条记录。

## 动效与可访问性

- Hover/Focus 110ms，浮层 180ms，使用标准减速曲线；不使用弹跳、持续呼吸和装饰扫描线。
- 尊重 `prefers-reduced-motion`。
- 正文对比度至少 4.5:1；颜色不是唯一状态信号。
- Tab 可完成主流程，Dialog 焦点不能逃逸，Esc 关闭后焦点返回触发元素。
