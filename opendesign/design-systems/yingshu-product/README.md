# yingshu-product

映述专属产品设计系统。它把产品定位为“主题或正文 → 旁白 → 配图 → 配音 → 成片”的媒体生产工作台，以审核效率、门禁可见性和可恢复任务为核心，而不是阅读体验。

## 设计立场

视觉方向为“冷中性媒体控制台”：冷白与石墨表面、单一信号蓝操作色、现代中文无衬线、克制的边框与高信息密度。核心界面模型为阶段概览、记录表、详情浮层和持续可见操作栏。
