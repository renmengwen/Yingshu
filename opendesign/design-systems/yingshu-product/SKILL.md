# 映述产品设计系统

## 使用边界

- 映述是视频生产工作台，不是阅读、书籍或说书产品。
- 以 `tokens/colors_and_type.css` 为唯一颜色与排版令牌来源，同时支持明色、暗色和系统主题。
- 重复结构化记录使用语义化表格与分页；详情和编辑进入 Dialog、Sheet 或独立详情视图。
- 保存、批准、生成、重试等阶段动作必须持续可见，保存与批准永远分离。
- 禁止纸张、书页、墨水、铜棕、衬线阅读正文、装饰渐变、发光卡和无意义仪表盘。

## 组件规则

- Input、Textarea、Select 静止态只有一层边界；`:focus-visible` 只显示一个 2px 焦点轮廓。
- Button 的移动端命中区不小于 44×44px；异步提交立即禁用并显示中文进行时。
- Table 行内只放扫描摘要、状态和操作；长文本必须能打开完整详情。
- Dialog 必须管理初始焦点、焦点循环、Esc、关闭后焦点返回和未保存拦截。
- Status 不能只靠颜色，必须同时使用明确中文文案。
- Sticky Action Bar 显示未保存数量、兼容性、阻断原因和当前可执行动作。

## 内容和视觉

- 主强调色为信号蓝；红色只用于失败和破坏性操作，绿色只用于成功。
- 中文正文统一现代无衬线；编号、时长、修订号、Job ID 和 Hash 使用等宽字体。
- 层级依靠留白、字号、字重和表面明度；阴影只用于浮层。
- 用户可见文案使用中文，直接说明当前对象、状态、原因和下一步。

详细规则见 `brand/style-notes.md`、`brand/voice-and-tone.md` 与 `ui-kit-yingshu/index.html`。
